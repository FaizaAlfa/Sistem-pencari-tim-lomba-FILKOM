# Sistem-pencari-tim-lomba-FILKOM
Mahasiswa kesulitan menemukan dan memvalidasi calon anggota tim lomba dengan keahlian spesifik karena pencarian masih bergantung pada platform pesan instan yang terfragmentasi, sehingga berdampak pada inefisiensi waktu rekrutmen dan hilangnya peluang berpartisipasi dalam kompetisi.
